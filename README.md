# API de Clientes

API REST desarrollada con Spring Boot para la gestión de clientes.

## Tecnologías utilizadas

- Java 21
- Spring Boot 4.1.1
- Spring Web MVC
- Spring Data JPA
- Hibernate
- H2 Database
- Bean Validation
- MapStruct
- JUnit
- Mockito
- Maven

## Requisitos

- Java 21
- Maven Wrapper incluido en el proyecto

## Ejecución

Desde la raíz del proyecto ejecutar:

```bash
.\mvnw.cmd spring-boot:run
